# 茶臼の森 事業ポジショニング・投資判断レポート

`index.html` だけで表示できる単一ファイルのレポートです。外部ライブラリ、画像ホットリンク、ビルド作業は不要です。

## GitHub Pages での公開

1. このディレクトリの `index.html` と `README.md` を公開用リポジトリのルートに配置します。
2. GitHub の **Settings → Pages → Build and deployment** で **Deploy from a branch**、`main`、`/(root)` を指定します。
3. 表示された公開 URL を開き、本文と回収試算が動くことを確認します。

公開ページには、提供された売上レポートと顧客データから集計した値が掲載されます。元のPDF、顧客名簿、個人情報はリポジトリに入れません。

## 数字の扱い

- 施策費用はメーカー・小売の掲載価格と仮予算の組み合わせです。発注前の見積もりではありません。
- 回収試算の初期値は仮定です。実際の客単価、販売手数料、清掃費、消耗品費で更新してください。
- 出典と調査上の制約は `index.html` の末尾に記載しています。
